# Резюме по ролям

PDF лежат в этой папке, исключённой из Git. `config.json` выбирает файл по
требованиям вакансии и языку. Холодная рассылка прикладывает резюме к тексту
одним сообщением; `--no-resume` отключает вложение, а явный `--resume` задаёт
один файл для всех получателей конкретного прогона.

## Основные варианты

- `resume-react.pdf` — русскоязычный frontend/React, запасной вариант по умолчанию.
- `resume-react-en.pdf` — англоязычный frontend/React.
- `resume-react-native.pdf` — React Native.
- `resume-fullstack.pdf` — Full-stack.
- `resume-nodejs.pdf` — Node.js.
- `resume-ml.pdf` — Machine Learning.
- `resume-ai.pdf` — AI/LLM.
- `resume-vue.pdf` — Vue/Nuxt.

Дополнительные варианты сохранены с суффиксом `alt` или `integrated`.

## Выбор

Порядок правил находится в `config.json`: React Native → ML → AI/LLM →
Full-stack → Vue → Node.js → язык вакансии. Для остальных frontend/React
вакансий выбирается русский или английский вариант.

Для российских компаний в сообщениях указывать Москву. Если спросят о зарплате,
подбирать ожидания по грейду, задачам и опубликованной вилке, в пределах
150 000–300 000 ₽. Junior-вакансии допускаются.

Перед прикладыванием нового PDF проверь, что файл существует и открыт.
Резюме не попадают в Git.
