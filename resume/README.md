# resume/ — резюме по стекам

Сюда Макс складывает PDF-варианты резюме, агент рассылает по стеку вакансии.

## Именование (обязательно)

```
resume-react.pdf       — React/TypeScript (основной)
resume-vue.pdf         — Vue/Nuxt (вакансии Vue)
resume-fullstack.pdf   — fullstack Node.js/TS (+Next.js)
resume-next.pdf        — Next.js-фокус (если будет отдельный)
```

Порядок выбора при отправке: точное совпадение стека вакансии → `resume-react.pdf` как дефолт.

## Правила отправки (канон)

1. **В холодных питчах резюме НЕ отправляется и не обещается** (политика
   Макса от 20.10) — файл уходит только в живом треде, когда HR сам
   запросил резюме/детали.
2. Отправка: `py tg.py sendfile @user resume/resume-react.pdf <caption>`
   — кириллица только через `py tg.py`.
3. PDF в git не попадают (`.gitignore`: `resume/*.pdf`) — только README
   и структура в репо.
4. Файл, который Макс скинул в чат позже PDF из этой папки, сильнее —
   использовать свежий.
